# Android 9 运行时文档

这里是 A9 客体运行时仓库的文档区，正在从宿主工程逐步迁移过来。迁移完成的章节各自成目录，目录里的 README 说明从哪里读起。

这一区只写与运行时本身有关的规则。构建链、产物与发布都以本仓库里的文件为准，宿主工程那边的说明只负责两者交界处的约定。

判断一次改动能不能用，看 GitHub Actions 的结论。产物本身也带自证：准备清单里每个原生文件记着字节数，ROM 包记着载荷哈希，发布工作流的最后一道闸门用打包器重读一遍包内清单，所以一个被手改过的包过不了这一关。

这个仓库单独克隆就能一路走到 ROM 包与 APK 侧的 payload。`scripts/build.sh` 里没有 Gradle 阶段，产物落在 `prepared/`、`prepared-apk/` 与 `dist/` 之后就停下，第三方定制者因此不必拿到整个宿主工程。
