# 版本索引

索引文件记下每次发布的产物事实，供下游按版本或按 tag 查哈希，也是将来发布门禁的输入。文件放在运行时仓库的 `release/` 下，随仓库提交。

不放在构建产物目录里，因为那个目录被忽略，每次构建都会清空，而索引要跨发布一直累积。

## 1. 一条记录有哪些字段

| 字段 | 含义 | 来源 |
| --- | --- | --- |
| 版本 | 标签，也是身份 | 输入 |
| 标题 | 发布页标题 | 正文脚本 |
| ROM 版本 | 包自己的版本 | 打包报告里的 romKey |
| romKey | 包的身份，由 id 与版本组成 | 打包报告 |
| 载荷哈希 | 载荷内容的哈希 | 打包报告 |
| 载荷字节 | 载荷字节数 | 打包报告 |
| 载荷文件数 | 载荷里的文件个数 | 打包报告 |
| 提交 | 这次发布对应的提交 | 标签 |
| 运行地址 | 产出这次附件的构建记录 | 第二道闸门 |
| 写入时刻 | 记录写入的时间，UTC | 写入那一刻 |
| 附件 | 每个附件的名字、字节数与哈希 | 附件收集脚本 |

字段顺序由脚本固定，读的人按名字取，不要按位置取。

## 2. 一条记录什么时候被覆盖

写入只有三行代码，位置在 `.github/scripts/update-release-index.mjs`。

```js
const updated = [
  ...entries.filter(item => item.version !== version),
  entry,
].slice(-maxEntries);
```

三行各做一件事，用一次重发画出来是这样。

```text
写入前    [ v1.0.0 , v1.0.1(旧) ]
                    │
                    ▼  剔掉同版本的旧记录
          [ v1.0.0 ]
                    │
                    ▼  把本次记录放到末尾
          [ v1.0.0 , v1.0.1(新) ]
                    │
                    ▼  从末尾截取一百条
          [ v1.0.0 , v1.0.1(新) ]
```

第一行剔掉这个版本的旧记录，历史上因为重试堆出来的多条一次清干净。第二行把本次记录放到数组末尾，历史顺序不变。第三行从末尾截取一百条，丢掉的是最早的那些发布。

同一个版本重发等于覆盖，旧的载荷哈希、附件与写入时刻一起换掉。要查这个版本的历次尝试，看 Actions 里的运行记录，那里才是完整历史。

## 3. 为什么能覆盖，覆盖的是什么

标签名在 git 里唯一，一个版本因此只有一个标签，记录的身份就是版本本身。文件里不会出现两条同一版本的记录，这是设计的结果，不是校验的结果。

覆盖的意义在别处。发布可能跑到一半失败，修好之后重跑同一个版本；标签也可能被删掉，在修过的提交上重新打回来。这两种情况都会让同一个版本再写一次记录，如果只追加，同一个版本就会留下两条哈希不同的记录，下游按版本查的时候无法说明哪一条是当前的。

比较是严格的字符串比较。版本必须是字符串，写成数字会让替换静默失效，之后每次发布都追加一条。脚本遇到不符合格式的记录会直接退出并提示手改，不猜也不修。

校验清单本身不进附件列表。它是校验文件，给它再算一个哈希只描述它自己，而每个读者本来就用它校验其他附件。因此一条记录里的附件比发布页上的文件少一个。

## 4. 索引怎样写回默认分支

发布成功之后，工作流在临时目录克隆默认分支，把新索引覆盖进去，提交一次再推送。三件事按顺序发生，每一件都有理由。

提交发生在 Release 创建之后，读索引的人不会看到有版本却没有文件的中间状态。默认令牌推送不会触发新的工作流运行，构建不会因此重跑，构建工作流另有索引目录的跳过规则兜底，换成别的凭据也不会把构建拉起来。推送之前先比差异，内容相同就跳过，重跑同一个版本不会留下空提交。

推送最多重试三次，每次先变基到远端。三次都失败就让整轮报红，交给人处理，不静默重试到成功。

## 5. 重入

整轮可以重入。写入是覆盖不是追加，重跑同一个版本只换记录内容。发布动作本身也是覆盖，同一个标签再发一次更新那条 Release，不新建。换一个新的版本号再发，索引与发布页两处都新增，那是另一次发布。

## 6. 判据

运行索引脚本，参数是文件路径、版本、标题、配置文件、打包报告、提交号、运行地址与附件清单。它输出一行，说明这次替换了几条、最后保留几条。

再用一行命令读出条目数与最后一条的身份：

```bash
node -e "const e=require('./release/release.json'); console.log(e.length, e.at(-1).version, e.at(-1).title)"
```

条目数不超过一百，最后一条的版本与标题属于刚发布的那一次。
